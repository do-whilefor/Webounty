# Third-party notices

This package adapts the Wiki/RAG prototype supplied by the user in Skills (1).zip, including lexical ranking, evidence-linked retrieval, knowledge annotations and method-card organization. New session publishing and capability-discovery code extend it. No Cairn implementation or third-party article text is bundled.

The CVSS calculator and portions of the method guidance derive from Web-Vulnhunt in Jase-SecKit. Scope Changed, floating-point roundup and input handling have been corrected to FIRST CVSS v3.1. Attribution metadata identifies reviewed inputs; it does not endorse historical case claims or make those files runtime dependencies.

The MIT notice is preserved in [references/web-vulnhunt-LICENSE.txt](references/web-vulnhunt-LICENSE.txt).

The Wiki overview/detail/negative-result organization and local observation comparison adapt ideas from Web-Vulnhunt's report structure, killed hypotheses, review log, negative-control harness, authorization matrix and patch verification. The original network shell scripts are not bundled. Their status-code heuristics and target-specific claims are not treated as evidence; reuse decisions are documented in [observation comparison](references/observation-comparison.md).

Normative scoring references: [FIRST Specification](https://www.first.org/cvss/v3.1/specification-document) and [User Guide](https://www.first.org/cvss/v3.1/user-guide). These documents are linked, not redistributed.
